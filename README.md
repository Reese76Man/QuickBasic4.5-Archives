# QuickBasic4.5-Archives
An archive of my QuickBasic 4.5 projects

Still Diceman, but changed the "Company" to Tronix Developers.  First it was GW-Basic to QuickBasic and then the QuickBasic 4.5 with Compiler... access to Interrupts (Come on, Mouse pointers!), but limited in graphics and sound (innately), and speed, of course... it was still a great platform to keep sharpening skills and getting to know the DOS PC environment with it.  I was given a copy of PowerBasic by someone, but maybe wrote one or two things with it before moving on.  ~Another link in the Microsoft Basic chain that I'd been exposed to over the years.

I've compiled as many of the programs as I could into a windows binary executables.  I also left in the old DOS ones, screenshots and what not.  Why, you say?  Why not!  Just dump it all and let it live forever inside that great Ai model in the sky!
-------------------------------------------------------------------

<pre>  
  [COMBO MAKER]       Combo.BAS/EXE - My first attempt at a self-extracting EXE software installation packager.  It worked pretty well (and still does) for what it was for.  Uses Master.EXE as the base installer!
  [DISK UTILITIES]    DiskCopy.BAS - Disc copier, duh!  I made m own floppy disk to file/file to floppy disk imaging utility.  And yes, it's very generous of me to give away this hot item after all of these years!
                      DiskEditor.BAS - Like my grandfather said, "If you want a track and sector editor done right, do it yourself!".  To this day, I never leave home without my trusty hex editor!
                      DiskLocker.BAS - I think this was my attempt at encrypting a whole floppy disk.  I asked Google's Gemini Ai to analyze this and IT seemed impressed, so... yeah. ;)    Actually, it's analysis was spot on and neat to read.
  [FILE UTILITIES]    FFind.BAS/EXE - F-Find "Finds files quickly and find find text in files". What my crap description was trying to say is that this searches folders/subfolders for files with specific texts in them.
                      Most.BAS/EXE - This utility scans a file and reports back on the top 10 ASCII values (or characters) found in said file.  I was probably thinking about compression or something when I wrote this.
                      PF.BAS/EXE (Print Formatter) - A simple utility that replaced non-printable characters in a file and output a clean textfile.
                      QUICK.BAS/EXE (QuickProtect v2.0) - My attempt at down and dirty file encryption.  It may be crude, but works fine for a household of non-hacker snoops!
                      TCOPY.BAS/EXE - A simple, single file copy utility.  Of course DOS had the COPY command, but I wanted a progress bar and built-in copy verification!
                      TVIEW.BAS/EXE (T-View v1.5) - A textfile viewer that allowed lateral and vertical scrolling!
  [GAMES]             BlackJack.BAS/EXE (Blackjack!) - Can you beat Cardshark Jack? This is a program I wrote during senior year of HS for Computer Science class.  It worked on their GW-Basic and QB45 was backwards compatible, so I added what amounted to an "About" screen and here it is! 
                      SF2093.BAS/EXE (Starfighter 2093) - Making a game in QB45 wasn't ideal, but cool visual demos and learning expeditions were all the rage for me.  It may be crap, but... no, it's crap.  Enjoy!
  [LOADCODE]          LCD.BAS/EXE (LoadCode v3.2) is a Binary File to Email-able Text Converter. File attachments are all the rage now, but back then, E-Mail wasn't so accommodating.  LCD_EXE.TXT is a converted version of LCD.EXE!
                      LCM.BAS/EXE - LoadComb was used when multiple LoadCode files needed to be combined before decoding them back into a binary file, making it LoadCode's companion tool and confidant!
  [MISCELLANEOUS]     DiceApp.BAS/EXE - A simple application for joining DICEnet, which spawned from The Flame Broiler BBS, which I ran.
                      Money.BAS/EXE - This unfinished project was supposed to be a spreadsheet-like personal bill tracker for household usage.
                      Pass.BAS/EXE - A simple test to see if I could store a password inside of the EXE and have it not be easily extracted via Hex editor (PW: REESEMANJACK)
                      TMATH.BAS/EXE - A utility that allowed me to perform simple math queries in my DOS prompt. A full on calculator GUI would have probably been the next step!
                      VirtualMemory.BAS - It basically opened a binary file, then I created peek/poke functions to use it as virtual memory.  It was a test demo just to see if it would work (and maybe had practical use later)
  [SOUND]             [VARIOUS].BAS - Once I discovered how to communicate with my Sound Blaster card, I went wild trying to see what I could do with it.  These are the programs that resulted from that experimentation!
  [TRONBASE]          TronBase.BAS/EXE - In 1997, my then-girlfriend worked at the mall for a place called HomeMart.  I wrote this to try and help them with inventory.  It was to run off of a floppy (uses HOMEMART.INV).
  [VIRTUAL TV]        TV.BAS/EXE - It's a virtual TV and in just 40 lines of code!  Yes, it uses an external datafile, but still.. fully functional in 2026!  Use +/- to "change" the channel. Use V and then +/- to "adjust" the volume.
  [WaveFormCD]        WaveCD.BAS - With a CD-ROM Kit for QB45, I was able to make a CD Player with some cool features.  CD Identification, Track Playlist, and soundwave oscilloscope!  It even had mouse support!
  [WORDFINDERMAKER]   WORDFIND.BAS/EXE - Nowadays, you simply ask Ai to make you a fun 25x25 grid wordfind puzzle... but this one doesn't run in a datacenter nor use frivolous colors, as in... all of them.  There are no ads and your data will NOT be collected!
  [ZOOMBASE]          DATA.BAS/EXE - A fixed-length person database that I created.  It featured a crude alpha-sorter, compression, merge, and the usual add/update/delete abilities.
