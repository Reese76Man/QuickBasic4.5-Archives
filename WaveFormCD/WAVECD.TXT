Introduction:

MAIN MENU
---------
Ok, the main menu consist of a lot of options. This is the screen that shows
up immediately after WAVECD is run. First I will explain options
which can be accessed via MOUSE or KEYBOARD. In the upper-left hand
corner of the main menu screen you will see the WAVE CONTROL, this is
where you choose which waveform to display. In the upper-right hand
corner of the main menu screen you will see the CD Player Controls.
You can Open the CD-Door if your CD-ROM has that option, Play, Stop,
Pause, Advance/Retreat One Track, or Advance/Retreat 15 Seconds. Also
some Sound Card controls (Sound Blaster Compatible) can be found, you can
adjust the CD Volume, which controls the sound going from the CD-ROM
to the sound card. This option controls how much sound will be going to the
wave & power meter from the CD. The other option is to control the Sound
Blaster Main Volume, this controls all sound coming out of the sound card
which is then played thru your speakers. In the center of the Main Menu
Screen you will see the wave-panel where 8 of the 9 waveforms will be
displayed. (All except for the Full Screen Wave)
In the lower-left hand corner of the menu screen you will notice the CD-Info
Box. This will give you current info on the CD (and tell you what CD and song
you are playing if it is programmed in). Also at the very bottom of
the info box you will see some more options. The first five are for editing
the Individual CD-Info stored on your Drive. Option (8) alone will
be explained in the next section. The rest of the options consist of:
J) Jump Track - Allows you to jump to any track on the CD without using +/-
Y) FPS Adjust - Allows you to set the auto-Frames Per Second Adjuster.
                The computer will try to keep the same Frames Per Second
                on the waveform in case your computer is too fast.
M) WaveCD.TXT - This options allows you to view this text file for help
                while running waveform.
R) Options - This is where you choose between REPEAT SONG, which repeats
             whatever song is playing over and over. REPEAT CD, which
             repeats the CD once it reaches the end. SHUFFLE, which will
             choose a random song but not the same 2 in a row. And PROGRAM CD
             which initiates the preset songs that you define in option (8),
             which is explained a little later on in this help file.

In the Right-Lower hand corner of the menu screen, you will see the power
meter and next to that will be the volume settings for the CD & Sound Card.

Option (8), CD-Detection Editor/Viewer
--------------------------------------
This is a full editor that will allow you to edit ALL CD's in your
collection that have been pre-read by the software without actually
having that particular CD in. You can also edit all of the tracks (up to
160) with the (C) option.  If you would like to view your collection,
just hit (V) and it will display the ALBUM and ARTIST and save it to
a file named "CD.LST" in case you want to print it out. If you have
a CD in already, the software will jump right to that CD to start editing.
If there is no CD, it will start at the first one in your collection.
Just scroll thru the CD-Collection using +/- and hit (S) to save info.
Also in this screen, you can define your PROGRAM CD.
